# Dataset card

## Synthetic demo

Generated deterministically by `cipherscope.datasets.synthetic`. Labelled synthetic. Host and peer identifiers are opaque hashes. Used for pipeline validation only.

## Registered research datasets

ISCX VPN-nonVPN, CIC-IDS2017 and USTC-TFC2016 are registered in `datasets/registry.py` but are never bundled. Loading them requires `--i-accept-dataset-license` after the user verifies the current terms. Data is never committed. See `scripts/download_datasets.md`.
